Command reference

Look up the command before running it. Each entry explains its purpose, relevant options, and where it runs. Service, firewall, file and DNS changes affect everyone sharing the VM. Examples in the modules remain the exercise instructions.

Linux commands · Windows commands · Script syntax

How to read the manual

Linux: use man COMMAND, press / to search, n for the next match, and q to exit. If local manuals are unavailable, use the linked Ubuntu manual. Bash built-ins use help COMMAND. Windows: use Get-Help COMMAND -Full or -Examples. Local PowerShell help may be incomplete; use the linked Microsoft documentation. Reading help does not execute the exercise command.

On Windows, open PowerShell with Run as administrator for changes to IIS, DNS and firewall rules. Get-Service can succeed even when Stop-Service cannot open the service due to missing elevation. Check hostname first so commands do not run on your own computer.

Linux and Bash

hostname

Run in: Ubuntu terminal

Show the machine name; confirm you are inside ccdc-linux before changing a service.

man hostname

Official manual: hostname

whoami

Run in: Ubuntu terminal

Show the current effective username. sudo whoami should print root.

man whoami

Official manual: whoami

sudo

Run in: Ubuntu terminal

Run a permitted command as another user, normally root. -l lists permissions; -u selects a user; -i starts a login shell; -n refuses a password prompt. Changes made as root affect the shared VM.

man sudo

Official manual: sudo

ip

Run in: Ubuntu terminal

Show network configuration. -br address gives a compact address list; route shows the routing table. These forms only inspect configuration.

man ip

Official manual: ip

ss

Run in: Ubuntu terminal

Inspect sockets. -l listening, -n numeric ports, -t TCP, -u UDP, -p owning processes, -H no header. sport = :80 filters local port 80. sudo reveals process details.

man ss

Official manual: ss

systemctl

Run in: Ubuntu terminal

Inspect or control services. status shows details, is-active reports state, stop causes an outage, start restores a service. --no-pager prints directly. A running service does not by itself prove its website works.

man systemctl

Official manual: systemctl

ufw

Run in: Ubuntu terminal

Inspect or change the Linux firewall. status verbose/numbered lists rules. insert 1 deny places a blocking rule first; delete NUMBER removes the rule at that current list position. Rule changes affect everyone and can disconnect access.

man ufw

Official manual: ufw

curl

Run in: Ubuntu terminal

Request a URL. -f fails on HTTP error status, -s hides progress, -S keeps errors visible, -i includes headers, --max-time 5 limits the request to five seconds. Test the supplied URL; 127.0.0.1 tests only the local VM.

man curl

Official manual: curl

date

Run in: Ubuntu terminal

Print time. -u uses UTC; +%Y%m%dT%H%M%SZ produces a sortable timestamp for an evidence-folder name.

man date

Official manual: date

journalctl

Run in: Ubuntu terminal

Read the system journal. -u selects a service, --since limits time, --utc uses UTC, -n limits lines, --no-pager avoids an interactive viewer. --user selects user-service logs.

man journalctl

Official manual: journalctl

mkdir

Run in: Ubuntu terminal

Create a directory. -m 700 allows access only to its owner. The evidence directory stores observations for the exercise.

man mkdir

Official manual: mkdir

stat

Run in: Ubuntu terminal

Show file metadata such as owner, permissions, size and timestamps; it does not establish who changed the file.

man stat

Official manual: stat

sha256sum

Run in: Ubuntu terminal

Compute a SHA-256 file fingerprint. Compare with a known-good hash to detect changed contents; a hash alone does not prove authenticity.

man sha256sum

Official manual: sha256sum

cat

Run in: Ubuntu terminal

Read file contents. In the exercise, redirection saves a copy in the evidence directory.

man cat

Official manual: cat

tee

Run in: Ubuntu terminal

Copy input to the screen and a file. It overwrites the file unless -a is used. sudo tee can write a protected file. 

man tee

Official manual: tee

tail

Run in: Ubuntu terminal

Read the end of a file. -n 100 selects the last 100 log lines.

man tail

Official manual: tail

df

Run in: Ubuntu terminal

Report filesystem capacity and use. -P gives a stable one-line-per-filesystem layout; / selects the root filesystem.

man df

Official manual: df

awk

Run in: Ubuntu terminal

Process text records. NR==2 selects the second line; $5 selects field five; gsub removes the percent sign; print emits the resulting usage value.

man awk

Official manual: awk

apt

Run in: Ubuntu terminal

Manage packages on the machine where it is run. update refreshes package indexes; install adds the named packages. The Remmina example runs on a student Linux computer, not automatically on the lab VM.

man apt

Official manual: apt

id

Run in: Ubuntu terminal

Show numeric IDs and group membership for a user.

man id

Official manual: id

getent

Run in: Ubuntu terminal

Query configured system databases. passwd NAME looks up the account record.

man getent

Official manual: getent

install

Run in: Ubuntu terminal

Copy files or create directories with chosen permissions. -d -m 700 creates an owner-only directory.

man install

Official manual: install

rm

Run in: Ubuntu terminal

Remove the named file. In cleanup, remove only the exact instructor-created policy file after preserving evidence.

Understanding the scripts

Bash evidence collection

case_dir="…" assigns a variable; $HOME expands your home directory; $(date …) inserts command output. Quotes keep spaces from splitting a filename. A pipe | sends text to the next command. > creates or overwrites a file; >> appends. Redirection is performed by the current shell: sudo cat file > copy reads as root but writes copy as your user.

Bash disk-usage inject

The shebang selects Bash. ${1:-75} uses the first argument or defaults to 75. [[ … =~ … ]] validates an integer, ! negates a test, || means OR, and (( … )) evaluates integer arithmetic. The script checks percent used, not free space. A threshold of 0 tests the alert branch without filling the disk. This script prints a message; it does not send email or schedule itself.

help if
help set
help [[
help let
man bash

PowerShell objects and disk-usage inject

param declares the threshold parameter, [int] specifies its type and [ValidateRange(0,100)] limits values. $disk stores an object; .Size and .FreeSpace read properties. -not, -or, -le and -ge implement tests. throw raises an error. -f formats a string. PowerShell pipes pass objects, so Where-Object filters records and Select-Object chooses properties.

@{…} is a hashtable used for the event filter. Parentheses evaluate an expression; a dot accesses a property or method. The Module 0 WindowsPrincipal expression checks whether the current process has the Administrator role; it does not elevate it.
